# quant-tools

Simple quantitative tools for analysing the market. It's a single web page with no backend, and everything runs in your browser.

## Tools

- **Position Size**: how many shares to buy so a stop-loss hit only costs a set % of your account
- **Returns & Risk**: paste prices to get total/annualised return, volatility, Sharpe, Sortino and max drawdown
- **Option Pricer**: Black-Scholes call/put prices and Greeks (delta, gamma, vega, theta)
- **Kelly Criterion**: optimal bet size from win rate and average win/loss
- **Compound Growth**: growth of an investment with monthly contributions

## Run it

Open `index.html` in any browser, or turn on GitHub Pages (Settings → Pages → Deploy from branch → `main`).
